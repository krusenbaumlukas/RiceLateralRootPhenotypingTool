Root scans of Rice (Oryza sativa) seedling roots:

Plants were grown in 5, 50 L containers (0.5x Yoshida solution, 10 μm P). At 14 days after sowing,
roots were scanned using a flatbed scanner.

Please note that these are just a few example images that can be used for testing the software. For the full image dataset refer
to: https://phenoroam.phenorob.de/geonetwork/srv/eng/catalog.search#/metadata/ef32b595-d705-4033-9375-86447b810b73.
